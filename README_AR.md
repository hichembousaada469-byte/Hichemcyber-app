# مشروع تطبيق أندرويد — Hichem Bousaada Portfolio (APK & PWA)

تحتوي هذه الحزمة على مشروع **Android Studio** جاهز بالكامل لتحويل موقعك إلى تطبيق أندرويد أصلي (`APK` / `AAB`) يعمل بسرعة عالية ويدعم الفتح المباشر لواتساب والإيميل وفيسبوك.

## الطريقة الأولى: استخراج ملف APK عبر Android Studio (الأفضل)
1. قم بفك الضغط عن ملف `HichemPortfolioAndroid.zip`.
2. افتح برنامج **Android Studio** واختر **Open** ثم حدد مجلد `HichemPortfolioAndroid`.
3. انتظر ثواني حتى يكتمل تزامن Gradle، ثم من القائمة العلوية اختر:
   `Build` -> `Build Bundle(s) / APK(s)` -> `Build APK(s)`.
4. سيظهر لك ملف `app-debug.apk` جاهزاً للتثبيت على أي هاتف أندرويد أو للمشاركة مع عملائك!

## الطريقة الثانية: التثبيت الفوري كتطبيق ويب تقدمي (PWA) بدون برمجة
- عند رفع ملفات مجلد `app/src/main/assets/` (`index.html`, `manifest.json`, `sw.js`) على أي استضافة مجانية (مثل GitHub Pages أو Vercel أو Netlify)، يمكن لأي زائر فتح الموقع من متصفح Chrome في أندرويد والضغط على زر **"تثبيت التطبيق على الهاتف"** ليتم تثبيته بأيقونة مستقلة وشاشة كاملة.

## المميزات المدمجة في نسخة الأندرويد:
- شريط تنقل سفلي أصلي (Bottom Navigation Bar) مخصص لشاشات الهواتف.
- معالجة أصلية في `MainActivity.java` لروابط واتساب (`wa.me`) والبريد الإلكتروني (`mailto:`) والهاتف (`tel:`) بحيث تفتح تطبيقات الهاتف مباشرة.
- دعم زر الرجوع في أندرويد (`onBackPressed`) وشريط حالة متناسق مع ألوان الثيم الداكن.
